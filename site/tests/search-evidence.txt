Search regression evidence — 2026-11-06

Cause (reproduced locally before editing)
The real ../data build contains 628 indexed topics and 19,337 indexed words.
Pagefind 1.6.0 returned 11, 16 and 26 results for qqzzxxnomatch, zzzzqqqq and
xkcdvvv respectively. Querying the browser API and loading the first result
showed highlighted Q. (Yang, Q.), Z. (Zhang, Z.) and X (Hyper Screening X).
These are reverse-prefix matches, not semantic matches or edit-distance typos.

Pagefind's find_word_extensions first finds indexed words starting with the
query; if none exist, it uses the longest indexed word that prefixes the query.
There is no minimum prefix length in that fallback, so one-letter tokens match.
Source (v1.6.0), pagefind_web/src/search.rs, find_word_extensions, lines 764–790:
https://github.com/Pagefind/pagefind/blob/v1.6.0/pagefind_web/src/search.rs#L764-L790

Inspected node_modules/pagefind/lib and types/internal.d.ts, plus its generated
dist/pagefind/pagefind.js runtime. The API strips punctuation, including dots
and hyphens, before searching. Its exact-search flag is enabled by quoting the
whole query; that changes searches to exact phrases and loses word prefixes.
The documented browser and indexing options provide no reverse-prefix/typo
switch, and ranking weights alter scores rather than candidate eligibility:
https://pagefind.app/docs/search-config/
https://pagefind.app/docs/config-options/
https://pagefind.app/docs/ranking/

Change
The search page now loads at most the first 50 candidate data records, verifies
every normalized query word of at least three characters against indexed content
at a word start, and uses the filtered data for rendering and the result count.
Normalization preserves case-insensitive, dotted/hyphenated names, diacritics,
and common -s/-ies plurals. Existing pagination, category filters, request guards,
error handling and the empty state remain covered by browser tests.
Scope: page caller, public pure matcher/filter, unit regression tests, real-data
browser script and package command; no data, pipeline, workflow or dependency edits.

Limits
Broad queries inspect only the first 50 candidates and report the filtered count
within that bound. The matcher preserves common plurals, not all of Pagefind's
English stemming (other inflections may be excluded). No new dependencies,
deployment, push or workflow dispatch; coordinator owns publication.
