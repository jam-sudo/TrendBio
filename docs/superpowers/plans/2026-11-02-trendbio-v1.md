# TrendBio v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Execution method chosen by the owner:** Codex workers (model "Astra") dispatched through the `orchestration` skill. Phase A is sequential; Phases B and C run in parallel on separate branches after A; Phase D after both. Each task is one worker dispatch; a fresh reviewer gates each task.

**Goal:** A daily, unattended pipeline that turns bioRxiv/arXiv/PubMed/GitHub/RSS activity into a ranked Top 5 of computational-biology topics, published as a minimal static site, with 12 months of backfilled history.

**Architecture:** A Python package (`pipeline/`) runs in GitHub Actions, writes JSON under `data/<domain>/`, and commits. An Astro project (`site/`) reads that JSON at build time and deploys to Cloudflare Pages on push. The two meet only at the JSON contract defined in Task A1; both are developed against the fixture dataset created there.

**Tech Stack:** Python 3.12, pydantic v2, httpx, feedparser, scikit-learn, numpy, sentence-transformers (`allenai/specter2_base`), `anthropic` SDK, typer, pytest + respx. Astro 5 (static output, TypeScript, no UI framework), `marked` for notes. GitHub Actions, Cloudflare Pages.

**Spec:** `docs/superpowers/specs/2026-11-02-trendbio-design.md` — every requirement below cites a spec section; read the spec first.

## Global Constraints

- Python **3.12**; Node **22**. Dependencies declared in `pyproject.toml` and `site/package.json`; no others.
- Repo is **public**: never commit keys, tokens or personal data; pipeline logs must never print `ANTHROPIC_API_KEY` or `GITHUB_TOKEN` (§15).
- Models: enrichment `claude-haiku-5-5`; daily synthesis `claude-opus-5-5`; backfill synthesis `claude-haiku-5-5` (§6.3, §6.6, §6.10). Exact ids, no date suffixes. Adaptive thinking is the default on both: do not send `thinking` or `budget_tokens`. Use structured outputs via `output_config.format`, never prefill.
- Daily run must finish in **< 30 min** on `ubuntu-latest` (§6.1). Daily LLM calls are synchronous; Batches API only in backfill (§6.3).
- Monthly LLM ceiling **USD 50**, read from `config/scoring.yaml`; above it, synthesis switches to Haiku and the day is `degraded` (§6.9).
- Taxonomy slugs are exactly the 11 in spec §5; they live in `config/taxonomy/computational.yaml`, never in code.
- All JSON on disk is UTF-8, 2-space indented, keys sorted (stable diffs).
- No network in unit tests; recorded fixtures only (§9).
- Site: light theme, one accent colour `#4f7cff`, white `#ffffff`, text `#111`, borders `#e5e5e5`; Inter or system sans; ≤ 3 type sizes per page; hero JS ≤ 30 KB; `prefers-reduced-motion` honoured; WCAG AA (§4.5).
- Tests exercise every stage without network (§9). Dry-run mode never writes to `data/` (§9).
- Commit messages: conventional prefix (`feat:`, `fix:`, `test:`, `docs:`, `data:`, `ci:`).

## Review Focus

Spec-implied conditions no single task's tests would otherwise exercise; each has a pinned test in the owning task.

1. **Safety-classifier refusal on a biology abstract** (pathogen genomics, toxin design). Expected: the item still gets a summary (first sentence of abstract, truncated to 160 chars) and a category from source hints; the run is not aborted. Pinned in Task B5.
2. **A day with zero clusters ≥ 3 items** (holiday week). Expected: the day file is written with an empty `ranked` list and status `ok`; site renders the day with a "Quiet day" message, not a crash. Pinned in Tasks B7 and C3.
3. **Re-running the same date** (manual re-dispatch). Expected: identical outputs overwrite, no duplicate items, topic history for that date replaced not appended. Pinned in Task B9.
4. **Topic continues but drops out of Top 5** then returns a week later. Expected: history has an entry with `rank: null` for unranked days, sparkline has no gaps, "topic history" lists only ranked dates. Pinned in Tasks B6 and C4.
5. **Operator note for a slug that no longer exists or has a typo.** Expected: site build warns and continues; no crash. Pinned in Task C4.

### Task B7: Scoring and ranking

**Interfaces:**
