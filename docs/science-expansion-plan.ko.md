추가 여섯 분야도 같은 방식으로 실제 재군집했다. 화학은 네 주에 각각 28·33·32·30개, 의학·보건은 10·6·1·8개 후보가 생겼다. 컴퓨터·정보와 공학은 네 주 모두 0개였다. 농림·수산·수의·식품은 마지막 주에만 1개, 사회과학은 첫째·둘째 주에 각 1개였다. 발행일·초록이 있는 위 표본에 한정된 결과다. 컴퓨터·정보와 공학에서는 발행 주기를 바꾸기 전에 학회와 조기 공개 자료원을 추가하는 편이 타당하다. ## Biology에서 먼저 검증할 것

상단에서 Biology와 Physics를 선택하고 Biology 안에서는 All Biology와 CompBio를 오간다. 베타 기간에 기존 홈과 CompBio 아카이브는 그대로 이용한다. 두 판은 각각 7일치 논문에서 관련성 판정과 군집화부터 다시 시작한다. 한 논문이 두 판에 실릴 수 있으며 순위의 모집단과 독자는 서로 다르다.

All Biology는 세포·분자, 유전, 발생, 개체·행동, 식물, 생태, 진화·고생물, 신경, 정량생물학, 미생물생태, 면역생물학을 포함한다. 첫 표본은 bioRxiv의 17개 주제와 PubMed의 11개 저널이다. 학회 발표, 지역 저널, 데이터셋 단독 출판, 현재 선정 밖의 생물학 하위 분야는 과소대표될 수 있다. 출처별 정확한 범위는 버전 관리한다. [수집 설정](../config/sources/biology.yaml) · [분류 기준](../config/taxonomy/biology.yaml)

베타는 공통 산식으로 시작한다. All Biology에서 코드 활동 점수는 0이다. 근거 다양성은 주제에 프리프린트와 출판 논문 중 한 유형만 있으면 0.25, 둘 다 있으면 0.50이다. 같은 유형 안에서 저널이 늘어도 이 점수는 같다. 처음 14회는 하위 분야별로 수집→군집→순위 전환, 저널별 비중, 같은 날 CompBio 상위 10개 주제와의 근거 DOI 중복을 기록한다. 수집에서 빠진 분야는 자료원을 보강하고, 군집 이후 밀린 분야는 같은 자료로 산식을 바꿔 순위를 비교한다. 기존 홈을 전환할지는 그 결과로 판단한다. ## 파일럿에서 운영으로 전환하는 기준

1. **수집 누락** — 최근 28일을 겹치지 않는 네 주로 나눠 하위 분야·언어·자료 유형별 원천 건수, 저장 건수, 중복과 초록 결측률을 낸다. API가 0건인 주, 요청 실패, 상한에서 잘린 주를 구별한다. 별도로 고른 저널 목차·학회 프로그램·도서 목록에서 대상 연구를 표집해 몇 건이 저장·군집·공개까지 도달했는지 분자와 분모를 기록한다. 그래야 수집기 밖의 누락도 보인다.
2. **요약과 분류** — 서로 다른 주와 하위 분야에서 상위·하위·탈락 사례를 각 10건 뽑는다. 공개 후보는 분야·군집의 일관성과 원문에 근거한 요약을, 탈락 사례는 제외 사유를 판정한다. 세트별 9/10은 초기 점검 기준이다. 표본 10건으로 분야 전체의 정확도를 추정하기 어렵다. 결론을 뒤바꾼 요약은 수정 후 새 표본으로 재검사한다.
3. **순위와 발행 주기** — 각 판 안에서 전체 군집과 상위 10개의 구성, 단일 저널 점유율, 분류별 상한의 영향을 비교한다. 현재는 출판 논문·프리프린트가 7일 안에 3편 이상 모여야 주제가 된다. 독립 데이터셋·학술서·장은 해당 유형을 식별해 군집을 만들 수 있는지도 검증한다. 드문 주제는 같은 자료를 7일과 28일로 각각 묶어 찾아낸 주제와 잘못 합쳐진 주제를 비교한다. 기존 주간·월간 화면은 이미 만들어진 일별 군집을 합산한다. [일별 처리](../pipeline/run.py) · [기간별 집계](../site/src/lib/periods.ts)
4. **운영** — 일간 베타 첫 14회에는 성공률, 실행시간, 에디션별 실제 비용과 전체 30일 예상액을 살핀다. 일별 판은 7일치 입력이 서로 겹치므로 대표성은 겹치지 않는 주 단위로 다시 본다. 월 55달러는 분야별 모델 전환 기준이며 계정 전체 예산은 따로 산정한다. 새 분야는 실측 비용과 전체 예산을 확인한 뒤 활성화한다.
5. **발행** — 출처 범위·판 이름·실제 기준 날짜를 명시한다. 독립 저장소 경로, 날짜별 영구 링크, 원문 링크, 실패 시 이전 판 유지, 기존 판의 아카이브 회귀 테스트를 확인한다. 운영 회고에서 다음 분야 공개·자료원 보강·발행 주기 변경 중 하나를 결정한다.
