# TrendBio 과학 분야 확장 계획

[English](science-expansion-plan.en.md) · 한국어

2026년 11월 20일(UTC) 재점검. **계산생물학(CompBio), 전체 생물학(베타), 물리학은 한국어와 영어로 공개 중이다.** 언어를 바꾸면 같은 날짜와 순위, 같은 근거 논문을 볼 수 있다. 수학·통계, 지구·환경, 화학, 항성·은하 천문학, 컴퓨터·정보과학, 공학, 농림·수산·식품·수의학, 의학·보건, 경제학·심리학, 인문·예술까지 10개 분야는 사이트 공개 전 시험 단계다. 시험판은 공개 GitHub 저장소의 Actions에서 실행하며, 로그인한 독자는 보관 기간에 결과물을 내려받을 수 있다. 항성·은하와 다른 물리학 분야를 포함한 arXiv 16개 분류도 물리학 확장판으로 시험한다. 계정 전체 월 예산은 첫 수집과 후속 날짜의 실제 비용을 비교한 뒤 정한다. [한국어 사이트](https://trendbio.dev/ko/) · [영어 사이트](https://trendbio.dev/)

파일럿을 실행하면 해당 날짜의 한국어·영어 읽기 파일을 함께 만든다. Actions 결과에서 압축 파일을 내려받아 풀고 `ko.html` 또는 `en.html`을 열면 된다. 언어를 바꿔도 같은 주제에 머무르며, 두 파일의 순위와 근거 링크를 저장된 발행본과 대조한다. 11월 4일자 10개 분야에서 주제 30개와 근거 논문 링크 91개가 모두 일치했다. 화학판에는 선정 기준을 충족한 주제가 없다는 안내가 나온다. 물리학 확장판 세 날짜를 포함한 13개 시험판에서 순위에 오른 107개 항목 모두의 한국어 제목과 짧은 요약을 검토했다. 두 언어판의 근거 논문 링크 338건도 일치했다. [날짜별 한국어·영어 시험판 내려받기](expansion-measurements/2026-11-20/reading-copies.md)

공개 사이트맵의 한국어·영어 페이지 1,115쌍을 대조해 순위·날짜와 외부 링크 20,425건이 일치함을 확인했다. 11월 19일자 공개 세 분야에서 각각 상위 5개 주제의 한국어 제목과 짧은 요약을 영어 원문과 대조했다. 단백질 언어 모델의 가중치를 고정했다는 뜻의 *frozen*도 바로잡았다. 공학과 농림 분야의 미리보기에서도 네 날짜별 판에 실린 주제 13개의 순서와 근거 링크 42개가 한국어·영어에서 일치했다. 해당 한국어 제목과 짧은 요약은 화분 시험과 포장 시험 등 연구 설계를 구분하는 용어까지 대조했다. [공개 아카이브와 시험판 대조](expansion-measurements/2026-11-20/bilingual-previews.json) · [공학·농림 분야 검토](expansion-measurements/2026-11-19/applied-pilots.json)

## 파일럿에서 운영으로 전환하는 기준

1. **수집 누락** — 최근 28일을 겹치지 않는 네 주로 나눠 하위 분야·언어·자료 유형별 원천 건수, 저장 건수, 중복과 초록 결측률을 낸다. API가 0건인 주, 요청 실패, 상한에서 잘린 주를 구별한다. 별도로 고른 저널 목차·학회 프로그램·도서 목록에서 대상 연구를 표집해 몇 건이 저장·군집·공개까지 도달했는지 분자와 분모를 기록한다. 그래야 수집기 밖의 누락도 보인다.
2. **요약과 분류** — 서로 다른 주와 하위 분야에서 상위·하위·탈락 사례를 각 10건 뽑는다. 공개 후보는 분야·군집의 일관성과 원문에 근거한 요약을, 탈락 사례는 제외 사유를 판정한다. 세트별 9/10은 초기 점검 기준이다. 표본 10건으로 분야 전체의 정확도를 추정하기 어렵다. 결론을 뒤바꾼 요약은 수정 후 새 표본으로 재검사한다.
3. **순위와 발행 주기** — 각 판 안에서 전체 군집과 상위 10개의 구성, 단일 저널 점유율, 분류별 상한의 영향을 비교한다. 현재는 출판 논문·프리프린트가 7일 안에 3편 이상 모여야 주제가 된다. 독립 데이터셋·학술서·장은 해당 유형을 식별해 군집을 만들 수 있는지도 검증한다. 드문 주제는 같은 자료를 7일과 28일로 각각 묶어 찾아낸 주제와 잘못 합쳐진 주제를 비교한다. 기존 주간·월간 화면은 이미 만들어진 일별 군집을 합산한다. [일별 처리](../pipeline/run.py) · [기간별 집계](../site/src/lib/periods.ts)
4. **운영** — 일간 베타 첫 14회에는 성공률, 실행시간, 에디션별 실제 비용과 전체 30일 예상액을 살핀다. 일별 판은 7일치 입력이 서로 겹치므로 대표성은 겹치지 않는 주 단위로 다시 본다. 월 55달러는 분야별 모델 전환 기준이며 계정 전체 예산은 따로 산정한다. 새 분야는 실측 비용과 전체 예산을 확인한 뒤 활성화한다.
