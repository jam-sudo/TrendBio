## Screen reader journey

On the published Computer Science landing the test starts with focus in the header search box. It types “regret”, submits the query, tabs through Search, opens the rank 9 result, expands its supporting papers and follows the first article to arXiv. The checks compare speech output from VoiceOver on macOS and NVDA on Windows with the result, rank and paper title. The test uses Chromium on both systems. All three environments passed. VoiceOver on macOS 15 and 26 and NVDA on Windows Server 2022 each announced “Supporting papers (4) for rank 9” and the first paper title. Each runner logs its spoken transcript. This was an automated run of the two screen readers. [macOS 15 and Windows results](https://github.com/jam-sudo/TrendBio/actions/runs/45253853644) · [macOS 26 results](https://github.com/jam-sudo/TrendBio/actions/runs/45254798054)
