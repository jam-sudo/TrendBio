# TrendBio readability and accessibility review

The November 21, 2026 production build contains 1,277 HTML pages. The sitemap lists 1,275. Search and the error page account for the remaining two. The inventory below includes every date and topic in the build. Search results and map filters were also exercised as interactive states. ## Findings and repairs

| Finding | Reader impact and repair |
| --- | --- |
| The skip link moved the viewport but left keyboard focus outside the main content. Direct visits to Search also moved focus to its input. | The first Tab now reaches the skip link and Enter focuses the main landmark. Submitting an empty header search still focuses the search box. Explicit tab order on the skip link also works with the default keyboard settings in desktop WebKit on macOS. |
| Small tool links competed with the surrounding clickable ranking card. The initial mobile scan flagged target size on 441 of the 1,268 pages available at the start of the review. | Tool links have a minimum 24-by-24 CSS-pixel target. Compact headlines have a minimum target height and wrap at desktop widths. Metadata and score labels use larger, relative type sizes. |
| Mobile archive dates had accessible names that could differ from the visible labels. | Calendar links now derive their names from the actual date and headline. The mobile name includes the month and publication status even when the calendar shows only a number. |
| Narrow tables broke decimal scores and labels across lines. | Score tables keep numbers intact and expose all columns in a named, keyboard-scrollable region. The same treatment applies to wide subject-count tables. |
| The research map’s accessible links omitted the relationships drawn on the canvas and did not reflect its filters. The count chart described its date range without exposing the bar values. | The map has a visible list disclosure with related topics, item counts and the same category and month filters as the canvas. Of 650 topics, the exercised category selected 106, and combining it with the first month selected 14 in all three browser engines. The list is available without JavaScript. The chart includes a dated count table and identifies the measure as a rolling seven-day count. |
| Field animations kept running alongside the text unless the operating system requested reduced motion. | Each of the 13 animated landings has a keyboard-operated pause control. The choice follows the reader between fields. Reduced motion and disabled JavaScript produce a still graphic. |
| Dense scientific paragraphs and subject lists made individual findings difficult to find. | Before the prose changes, 1,061 main-content paragraphs across 797 pages exceeded 100 words. The final scan counted 21,316 main-content paragraphs and none exceeded 100 words. Archived research text and generated syntheses were divided at sentence boundaries. Long arXiv subject inventories now use lists, and the ranking guide defines each component separately. The word count is a reading-density measure for this snapshot. |

## Verification and scope

Every page was opened in Chromium with real production data. The WCAG 2.2 A/AA axe rules ran in desktop dark mode at 1,280 CSS pixels and mobile light mode at 320 CSS pixels. The mobile run opened main-content disclosures. Across the built pages, 54,992 distinct per-page internal link destinations resolved, including their fragments when present. A separate pass tested the skip link with actual keystrokes, the heading outline, duplicate IDs, main landmarks, ordinary reflow and WCAG text spacing. Another pass doubled the root text size at 640 CSS pixels and checked for page-wide horizontal overflow. Named table regions can scroll independently. [WCAG 2.2 criteria](https://www.w3.org/TR/WCAG22/) · [Repeatable browser audit](../../site/scripts/audit-accessibility.mjs)

All four passes finished on the full inventory. Axe reported zero A/AA violations in both configurations. Its remaining review notices concerned contrast, including glyph-only controls and cases where axe could not determine a text background. A separate calculation compared the computed foreground with the composited solid background of those elements. The CSV includes the lowest ratio measured by that follow-up on each page. Blank values mean that the page had no contrast notice for that configuration. The calculation measures CSS colors and does not measure image pixels.

Additional browser checks covered keyboard search through to the matching result, category and month filtering, a scrollable score table, saved motion preferences and the reduced-motion preference in Chromium, Firefox and WebKit. Chromium also exercised forced colors and the non-JavaScript map and hero. Visual inspection covered long ranking headlines, long scientific prose, a field landing and numeric cells on a narrow screen.

The audit covers TrendBio’s English HTML and its internal navigation. Browser accessibility-tree inspection formed part of the checks. Listening tests with VoiceOver, NVDA, TalkBack or actual readers, and an editorial assessment of the scientific accuracy of every article, remain outside the results.
